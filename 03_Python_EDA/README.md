# Python – Steel Plant Dispatch Exploratory Data Analysis (EDA)

This folder contains a comprehensive Exploratory Data Analysis (EDA) of steel plant dispatch operations using Python.

## Tools & Libraries
- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook

## Key Components

1. Data loading and exploration
2. Data cleaning and quality checks
3. Missing value and duplicate analysis
4. Statistical analysis
5. Monthly dispatch trend analysis
6. Customer-wise dispatch analysis
7. Product-wise dispatch analysis
8. Destination-wise dispatch analysis
9. Quality and shift analysis
10. Correlation analysis
11. Business insights and visualizations

## Visualizations

The project includes 11 charts covering:
- Monthly dispatch trends
- Top customers
- Product-wise dispatch
- Top destinations
- Quality mix
- Shift analysis
- Interval analysis
- Quantity distribution
- NSR distribution
- Customer Pareto analysis
- Correlation matrix

## Business Objective

To identify dispatch patterns, customer concentration, product performance and operational insights that can support better business and supply chain decisions.
