# Steel Plant Dispatch Analytics

An end-to-end data analytics project focused on steel plant dispatch operations, production performance, product analysis, and supply chain insights.

## Project Overview

This project analyzes steel plant dispatch data to understand operational performance, identify business trends, and generate meaningful insights using Excel, SQL, and Python.

The objective is to explore dispatch operations from a business perspective and demonstrate how data analytics can support better operational and supply chain decisions.

## Tools & Technologies

- Microsoft Excel – Data analysis and reporting
- SQL – Data querying and business analysis
- Python – Data cleaning, EDA and visualization
- Pandas & NumPy – Data manipulation
- Matplotlib & Seaborn – Data visualization
- Jupyter Notebook – Exploratory analysis
